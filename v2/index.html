Play with Ableton Live

Not connected

Polyphemus follows Live's MIDI clock and sends its notes into Live as they play, chance and humanize included. Needs Chrome or Edge on a computer.

Setting up Live on a Mac
  1. In Audio MIDI Setup, open Window → Show MIDI Studio, double-click IAC Driver and tick "Device is online".
  2. In Live's Settings → Link, Tempo & MIDI, turn on Sync for the IAC Driver output (clock to Polyphemus) and Track for the IAC Driver input (notes from Polyphemus).
  3. Here, choose the IAC Driver bus for both Clock in and Out.
  4. In Live, create a MIDI track per part: input "IAC Driver", channel 10 for drums (into a Drum Rack), 1 for bass, 2 for lead, 3 for pad, Monitor set to In. Don't route any track's output back to the IAC Driver.
  5. Press Play in Live. Polyphemus answers each clock pulse about 20 ms later (80 ms with its built-in sounds on), so set Live's MIDI Clock Sync Delay for the IAC output to about −20 ms, then fine-tune with the Offset slider here.

MIDI clips for Ableton Live

Exports the current pattern slot. Each file drops onto a clip slot as its own clip. A full cycle runs until every lane in the track lines up again and lands on a bar line, so the clip loops seamlessly in Live; cycles longer than 64 bars stop at 64. Chance and humanize stay in Polyphemus unless you bake them in, which renders one take.

Share or restore a pattern

A pattern code holds the current slot plus tempo, key, and sound settings. Paste one here and choose Load code to replace the current slot.

Space plays and stops. Keys 1–4 pick a track. Pattern switches wait for the next bar while playing. The original 2016 Polyphemus is archived in the repository under v1/.
